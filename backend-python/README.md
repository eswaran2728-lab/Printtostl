# PhotoToSTL Pro — Blender Python Backend

This backend handles 3D mesh repair and optimization using Blender's Python API.

## Setup
pip install -r requirements.txt
python app.py

## API Integration Points
- Meshy API: https://docs.meshy.ai
- Tripo API: https://platform.tripo3d.ai
- Hunyuan3D: self-hosted
- TripoSR: open source
